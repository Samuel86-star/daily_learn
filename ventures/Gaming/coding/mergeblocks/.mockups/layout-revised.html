📐 改进要点

1. 任务卡片化凸显
• 黄色发光边框 + 标题"本局目标"
• 每个任务独立卡片：图标+文字+奖励
• 完成状态：绿色勾 + 绿色边框
• 尺寸比原来大 30%，目标感更强
2. 里程碑压缩为一行
• 方块缩小到 20px，只显示 7 个
• 进度条放在右侧（横向填充）
• 当前里程碑放大 1.1x + 黄色高亮
• 整体只占一行高度
3. 棋盘最大化
• 减少 gap（从 8px 到 3px）
• 棋盘区域 flex:1 自动占满剩余空间
• 底部道具固定高度，不侵入棋盘
• 小屏自动缩小 cellSize 适配
4. 连击不常驻
• 连击 ≥2 时顶部弹出浮动面板
• 3 秒后自动消失，不挤占空间
• 分数变化时只在分数数字上做金色跳动动画
• 保持顶部简洁
