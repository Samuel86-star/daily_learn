# Competitor Analysis Output Schema

Use this format for each candidate:

```text
## <Game Name>

30-Second Player Action:
<What the player is doing within the first 30 seconds.>

Replay Hook:
<Why the player wants one more round or one more session.>

Low-Art Implementation:
<How to implement the mechanic with simple UI, icons, shapes, particles, or generated assets.>

China Localization Directions:
<2-4 theme directions suitable for WeChat or Douyin Mini Games.>

Main Risks:
<IP, cloning, production, platform, retention, or monetization risks.>
```

End with:

```text
## Top 5 Priority

| Rank | Candidate | Reason |
|---|---|---|
```
