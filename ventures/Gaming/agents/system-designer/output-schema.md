# Senior Game System Designer Output Schema

For a light concept brief:

```text
## <Concept Name>

Inspired Mechanic:
<Mechanic family, not copied game expression.>

Positioning:
<One-sentence game pitch.>

Core Loop:
<Action -> feedback -> reward -> next action.>

Low-Art Direction:
<Simple visual approach.>

Why It Can Work:
<Short reason.>

Main Risk:
<Biggest concern.>
```

For a full system design:

```text
# <Game Concept> System Design

## Positioning
<Target player, session length, platform fit, and core promise.>

## Core Loop
<Primary loop and secondary loop.>

## Core Rules
<Deterministic rules that define play.>

## Level or Content Structure
<How levels/content are produced, paced, and scaled.>

## Progression
<Unlocks, difficulty, resources, collections, or goals.>

## Retention
<Day 1, Day 2-3, and Day 7 retention hooks.>

## Monetization
<Ad or purchase points. Keep MVP modest.>

## Low-Art Production Plan
<Minimum assets, UI style, effects, and optional generated art.>

## MVP Scope
<What to build first, usually within 7 days.>

## Risks and Avoidance
<Cloning/IP risk, design risk, production risk, platform risk.>

## Validation Metrics
<What success looks like in a prototype test.>
```
